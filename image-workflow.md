# Mandatory Image Workflow

1. Extract requirements and exact text.
2. Inspect and classify reference assets.
3. Perform feasibility, risk, and format analysis.
4. Select visual genre and art direction.
5. Select supported model, ratio, dimensions, and output type.
6. Write production prompt and relevant negative constraints.
7. Check tool limits and costs.
8. Generate and wait for completion.
9. Inspect actual output.
10. Evaluate brief compliance, craft, technical integrity, and content integrity.
11. Diagnose defects and apply targeted corrections.
12. Upscale/resize/export only when supported.
13. Inspect the final file.
14. Deliver with the mandatory Image Production Report.
