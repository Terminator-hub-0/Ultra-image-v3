# Global Style Catalog

Use this catalog to pick, combine, or translate a requested style into concrete visual traits. It is a menu, not a limit.

**The user's requested style always comes first.** If the user names a style (stickman, anime, cyberpunk, watercolor, a festival look, anything else), produce exactly that style. If it is not listed, break it into concrete traits (medium, era, palette, line/brush quality, lighting, texture, composition) and produce it. If the user names no style but gives an occasion (for example Diwali or a birthday), choose the best-fitting style from section 8 and state the choice.

**Rule for living artists and trademarks:** never imitate a living artist's exact style or reproduce branded characters. Translate the request into high-level traits (palette, line quality, composition, mood).

## How to apply a style
1. Pick one primary style, plus at most one or two compatible secondary influences.
2. Write the concrete traits into the prompt: medium, era, palette, line or brush quality, texture, lighting, lens/camera, composition, and finish.
3. Do not blend incompatible styles by accident (for example photoreal skin on flat cel-shaded anime) unless the user asked for the mix.
4. Inspect the result against the chosen style's own rules, not only against photorealism. Simple styles (for example stickman) must stay clean, consistent, and readable, with no stray detail.
5. Intentional style traits (grain, glitch, sketchy lines, flat shapes) are not defects. Mention them in the report as intentional.
